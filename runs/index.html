Learning Curriculum Builder

Give it a learning goal, a time budget and a learner profile. An agent searches YouTube, reads the transcripts, and builds an ordered curriculum where every pick is justified by quotes from the video itself — then it stays to answer why, or to change the plan on request.
1. Plansub-topics & feasibility
2. Searchgather a candidate pool from YouTube
3. Readtranscripts — what each video actually teaches
4. Choosepick & order, grounded in verified quotes
5. Verifycode checks the quotes, budget & red flags
A tool-using agent that decides each step for itself. See How it works for the design, and the evaluation for how it scores.

Curate your own

Describe a learner and press Build. The agent loop runs live and streams its work — searching, reading transcripts, choosing — into a chat on the left while the curriculum takes shape on the right. Then you can ask it why, or tell it to change things. Available when the site is served with uv run curriculum serve; a brand-new goal takes 1–2 minutes.
