But knowing that relationship exists isn't enough. We also need to understand how strongly the size of a house affects its price and how that relationship changes when other features are involved. So we need a mathematical way to measure prediction error. This is where the loss function comes in. A loss function measures the discrepancy between the model's prediction and the actual target.

For regression, one common choice is squared error. Let's understand why we square the difference. First, squaring makes the error non-negative, so positive and negative prediction errors don't cancel each other out. Second, it gives larger errors a disproportionately larger penalty. But remember, we're not training our model on one house.

We have an entire dataset, so we calculate the squared error for every training example and take the average. This gives us mean squared error, or MSE. Here's what this equation is doing: for every example, we generate a prediction using our model. We compare that prediction with the actual value.

We square the difference. And finally, we average those errors across the dataset. The resulting value tells us how well our model is performing according to this loss function. Now, notice something interesting. Our predictions depend on the model parameters, and our loss depends on those predictions.

Different positions on this surface correspond to different parameter values. Our objective is to move toward a region where the loss is smaller. The gradient tells us how the loss changes when we change the parameters.

In particular, it points in the direction of steepest local increase. So if we want to reduce the loss, we move in the opposite direction. That's the intuition behind gradient descent. We represent the update mathematically as theta t plus one equals theta t minus ETA times the gradient of L at theta t. Here, theta t represents our current parameters.

Nabla L of theta t is the gradient of the loss with respect to those parameters. And ETA is the learning rate. The learning rate controls how large each update should be. If it's too large, we might overshoot a good solution. If it's too small, training can become unnecessarily slow.

So we repeatedly compute gradients and update the parameters, attempting to reduce the loss. Notice that gradient descent doesn't need to know the location of the minimum beforehand. It uses the local gradient to decide how to change the parameters. And that's the fundamental training process. We choose a model, make predictions, measure the errors and update the parameters to improve those predictions.

The loss function determines how we evaluate the predictions, and the optimization algorithm determines how we search for parameters that reduce the loss. These three components form the foundation of many supervised machine learning systems.

But there's another problem. Suppose our model achieves an extremely low loss on the 1,000 houses we used for training. Does that mean it will accurately predict the price of a new house? Not necessarily. Because fitting the training data and learning a relationship that works on unseen data are different things. This is called generalization. Our objective isn't simply to memorize the examples we've already observed.

We want to learn relationships that remain useful when we encounter new examples. To evaluate this, we typically separate our dataset into training, validation and test sets. The training set is used to learn the parameters.

The validation set helps us make decisions about the model during development. And the test set provides a final evaluation on data we haven't used to train or select the model. A model might perform extremely well on the training set but poorly on the test set.

This is commonly associated with overfitting. In simple terms, the model may have fitted details or noise specific to the training data instead of learning a relationship that generalizes. But what happens if that assumption is wrong? What if the relationship is non-linear? And this is a limitation of the model representation, not necessarily the optimization algorithm.

So let's connect everything we've learned. Machine learning is about using data to learn useful relationships. We represent those relationships using mathematical functions. We choose a model class and learn parameters that control the function. We use a loss function to evaluate predictions. We use optimization methods to search for better parameters, and we evaluate whether the resulting model generalizes to unseen data.

That's the basic mathematical framework behind supervised machine learning. But remember, we've been working with a model that predicts a continuous numerical value like a house price.
