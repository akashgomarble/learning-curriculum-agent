Plan

Assumptions I made
  • 'Better at design' means UI/visual design for web and app interfaces, not branding or UX research.
  • The learner has no design-tool experience. Figma is shown, but the focus is on principles they can apply in CSS.
  • Everything in the pool is assumed to date from 2020 or later. None of the videos is flagged as outdated.
  1. Core principles: contrast, repetition, alignment, proximity
    This gives a shared vocabulary for critiquing any UI.
  2. Spacing, layout and the 4/8-pt grid
    Spacing is the fastest visible improvement, and it maps directly onto the learner's CSS skills.
  3. Typography and hierarchy
    Most UI is text. Size, weight and color create the hierarchy.
  4. Color palettes
    This helps the learner build palettes that look good together.
  5. Depth, shades and shadows with quick redesigns
    A fast, repeatable way to lift flat UIs, shown on before/after examples.
  6. Full redesign walkthrough (critique + apply)
    Applies every principle to one real UI from start to finish.
  7. Real project process and developer handoff
    Shows how design decisions, feedback and accessibility work on a live project.
